# RADAR Retos

Retos cortos para reconocer señales de captación en chats y redes.

Live: https://lotuslatte.github.io/radar-retos/

The app is a single self-contained `index.html` (fonts and assets inlined) and works as an installable PWA with offline support.

## Install

- Desktop (Chrome, Edge): open the link and click the install icon in the address bar, or menu > Install app.
- Android (Chrome): menu > Add to home screen / Install app.
- iPhone and iPad (Safari): Share > Add to Home Screen.

Progress is saved in the browser's local storage on each device.
